# OTEPZ Roblox Scripts
Hosting: https://aiotep.my.id

## Cara Pakai

### Delta / Fluxus / Krnl / Executor lain
Tempel di executor:
```lua
loadstring(game:HttpGet("https://aiotep.my.id/loader.lua"))()
```

Atau langsung load script utama:
```lua
loadstring(game:HttpGet("https://aiotep.my.id/main.lua"))()
```

## Files
- `loader.lua` — Loader ringan, auto-fetch `main.lua`
- `main.lua` — Script utama (Auto-Farm Universal)
- `CNAME` — Domain redirect (aiotep.my.id)
- `.nojekyll` — Biar GitHub Pages serve `.lua` file langsung

## Update Script
Kalau mau update script, tinggal push ulang `main.lua` ke repo ini.
Loader otomatis ambil versi terbaru (tanpa ubah URL di executor temen lu).
